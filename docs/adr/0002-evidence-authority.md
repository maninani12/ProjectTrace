# ADR 0002 — deterministic-first verification and no repository execution

Accepted: Python AST and manifest facts precede explanation. Imports support inference, missing evidence supports uncertainty, and current opposing configuration can create a scoped contradiction. Every verdict retains provenance, version and limitation. Human decisions do not change the underlying analyzer status.

Repository files are data. No installation, build script, hook, shell or infrastructure command runs. The external-AI boundary has no tools, validates citation IDs and redacts/limits context; external AI remains disabled. Semantic retrieval and prompt evaluations are deferred rather than simulated.
