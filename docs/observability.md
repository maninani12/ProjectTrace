# Observability

The API adds X-Request-ID and records structured method/path/status/duration fields through the projecttrace logger. Raw request bodies, source and credentials are not included. Uvicorn process logs are available during native development.

OpenTelemetry API is present through the framework dependencies, but an SDK/exporter, distributed spans, tenant metrics dashboards, queue saturation metrics and production alerting are not configured. Do not claim exported tracing or production SRE visibility. Health/readiness and measured local benchmark reports are the currently verified signals.

Native ZIP/JSON imports create durable job records with stage history, timestamps, warnings, errors, request ID, snapshot ID and analyzer counts. The projecttrace.pipeline logger emits safe JSON stage records with organization/repository/job IDs and elapsed duration. Generation publication adds staging-batch counts, maximum Record batch size, receipt reuse and completed computation checkpoint hits. Inspect these together with generation state, branch pointer revision and retained input expiry; a terminal job alone does not establish that an unfinished generation was published.

As of 15 October 2026, actual worker-process termination at three publication boundaries and PostgreSQL connection termination before promotion have local recovery tests. Fourteen receipt boundaries also have fresh-Session replay tests. Real Redis/Celery interruption/redelivery remains unqualified in this environment. Stage component times can overlap; use captured end-to-end wall time rather than summing component counters. Parent-process profiles and sampled child-process resources have explicitly different measurement scopes. See `GENERATION_AND_LEARNING.md` and the current acceptance register. Exported production telemetry remains deferred.
