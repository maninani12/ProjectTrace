IMPORTANT:

This specification defines the approved direction for ProjectTrace
Code Quality / Code Intelligence.

Treat the CURRENT implementation as a BASELINE.

Do NOT assume the current Code Quality module is industry-ready merely
because:

- it renders successfully
- it produces some findings
- tests pass
- metrics appear on screen
- regex rules work
- a quality score exists
- the dashboard looks polished

The objective is to transform ProjectTrace Code Quality into a
professional engineering capability that experienced developers can
trust on real repositories.

DO NOT rebuild working functionality unnecessarily.

FIRST:

inspect the actual latest ProjectTrace repository.

Determine:

what currently exists
what actually works
what is superficial
what is duplicated
what is incomplete
what is technically weak
what should be retained
what should be refactored
what should be replaced.

Do not guess implementation status.
