# Demo guide

Read CEO-DEMO.md for the main story. Seeded repositories are Northstar Identity, Payments, Commerce events and Platform Status. Every screen shows DEMO DATA. The credential fixture is synthetic and cannot access a provider. Vulnerability references are real cached OSV advisory IDs.

The clean system has no findings within supported rule coverage; it is not declared universally secure. Architecture and unsupported API claims remain unverified when source evidence is missing. Re-running the seed is idempotent and preserves prior matching records. For a pristine reset, use a new disposable database and migrations rather than deleting customer data.

The demo works without live GitHub, cloud or LLM uptime. Fonts are bundled locally. Follow the story control opens a short, skippable walkthrough.
